# Evaluation results

No model-effect result has been run or claimed in the author draft.

Independent results belong here as immutable paired-run artifacts containing:

- exact model identifier or snapshot and runner version
- system instruction and sampling configuration
- condition (`baseline`, `full_book`, or `compact_ablation`)
- recorded case order and seed
- raw response JSONL
- scorer JSON
- run date and operator
- aggregate report with every run, family scores, control score, mean, and spread

Null results, regressions, parse failures, and false-restraint tradeoffs must be retained.
Do not replace raw results after inspecting them. Any answer-key or scorer change creates
a new evaluation version.
